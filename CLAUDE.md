# Outlit Agent Skills

Available skills in this repository:

- **[skills/outlit-sdk/SKILL.md](skills/outlit-sdk/SKILL.md)** — Decision-tree-driven guide for integrating Outlit SDK. Covers all web frameworks (React, Next.js, Vue, Nuxt, SvelteKit, Angular, Astro), server runtimes (Node.js, Express, Fastify), desktop apps (Tauri, Electron), and Rust. Handles new installations, analytics migrations, auth integration, consent management, activation events, billing lifecycle, and troubleshooting.

- **[skills/outlit-cli/SKILL.md](skills/outlit-cli/SKILL.md)** — Quick reference for the Outlit CLI (`@outlit/cli`). Covers authentication, customer/user queries, SQL analytics, AI agent setup, and common workflows. Complements `--help` with credential chain, output behavior, and usage patterns.

Load the SDK skill when users need to integrate Outlit customer journey tracking. Load the CLI skill when users run `outlit` commands or set up Outlit for AI agents.
